# 主列表即报告任务集合（取消独立的「已勾选」状态）

主窗口原先并存两个状态：「已加入」（进入列表）与「已勾选」（纳入报告），二者可分离——任务能留在列表却不参与生成。这导致选择任务窗口把「已加入」误当「已勾选」，以及取消勾选后的任务从窗口消失、无法重选。决定：合并为一个状态，**主列表中的任务即纳入报告**；从列表移除靠每项的小 × 或整表「清空」，而「选择任务」窗口只呈现尚未「已加入」的任务。代价是失去"临时保留但不参与生成"的能力，但该能力无人真正使用。

## Considered Options

- **保留双状态，修正选择窗口的排除键**（issue #10 的做法）：仍允许"在列表但不参与生成"，但双状态语义持续令人困惑、两个窗口职责重叠。
- **主列表即报告集合**（本决定）：单一状态，两个窗口的职责彻底分开。

## Consequences

- 主窗口任务项不再有勾选框；「全选/取消勾选」消失，改为每项 × 与整表「清空」。
- 选择任务窗口的默认全选简化为"全部可加入的新任务"，不再需要区分"已加入但未勾选"。
