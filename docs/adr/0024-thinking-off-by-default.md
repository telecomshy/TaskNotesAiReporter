# 「思考」默认关闭：按模型能力表映射参数，自定义供应商填参并实测验证

「思考」（模型生成正文前的内部推理）实测占生成时长约九成（`docs/research/thinking-toggle-apis.md`，含本地探测：DeepSeek 开思考 ~20s / 关思考 ~3.5s），决定把它做成插件设置：每个 模型 条目一个「思考」三态（**自动 / 开 / 关**），出厂默认**关**。预设供应商（DeepSeek / 阿里云百炼 / Kimi / MiniMax / 智谱 GLM）只显开关，参数暗号由插件内置的**按（供应商, 模型）能力表**映射（能否关、关参数、开参数）；关不掉的模型（Kimi K3、MiniMax M3.1-Flash、GLM-5.3 全系）置灰标注，无思考的模型（moonshot-v1-*、GLM-4-long 等）不发参数。自定义供应商由用户填「思考参数名」（留空＝不发）＋ **测试按钮**发微型请求实测（✅ 生效 / ⚠️ 假关 / ❌ 拒收，结论带验证时间）。一次请求只发**一个**开关参数。400 拒收归 `ai-error` 上浮、不降级重试。

## Considered Options

- **纯静态能力表、无验证**：表会过时，且 HTTP 200 ≠ 关掉了（实测 DeepSeek 静默忽略未知字段、MiniMax M2.x 假关）——保留表但降为默认种子，测试按钮实测定论。
- **纯用户透传（JSON 请求参数字段）**：把术语学甩给用户——降级为自定义供应商的「思考参数名」字段，且可测试。
- **保存设置时自动探测**：暗地花钱、失败无声——改手动按钮 + 生成时被动告警。
- **默认「自动」（零行为变化）**：与「思考默认关闭、生成要快」的产品诉求相悖——取默认关，行为变化点写进规格。

## Consequences

- 升级后能关的模型默认变快；默认值是产品决定，改变它须回翻本 ADR。
- 内置能力表按（供应商, 模型）记录能力与参数，随 `docs/research/thinking-toggle-apis.md` 维护；不可关型号置灰并标注「此模型强制思考」，无思考型号标注「此模型无思考」。
- 一次请求只发一个开关参数：DashScope 的 `thinking_budget` 与 `reasoning_effort` 互斥，同发报错。
- 验证以响应的 `reasoning_content` / `reasoning_tokens` 为准，不信任 HTTP 200；智谱 `usage` 未文档化推理计量，按 `reasoning_content` 判。
- 「设了关仍有推理段」＝假关：生成后给一次性非阻断告警。
- 围栏：流式渲染、推理强度档位、通用 JSON 透传不做。
