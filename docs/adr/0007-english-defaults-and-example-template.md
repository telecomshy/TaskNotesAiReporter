# 默认示例模板与默认/回退报告语言改为英文

插件原先的默认示例模板（`tpl_weekly_example`）与默认报告语言均为中文。决定：默认示例模板的**名称与正文改为英文**，`DEFAULT_SETTINGS.language` 改为 `"English"`，且空/纯空白的报告语言在载入（`normalizeSettings`）与保存（设置页）时都回退为 `"English"`（取代 [ADR-0006](./0006-report-language-declaration.md) 的「中文」）。同时做一次性迁移：仅当示例模板的 `id == "tpl_weekly_example"` 且 `name`/`content` 仍逐字等于旧中文默认值时，替换为英文版；任何用户改动或其它 id 一律保留。**不**迁移用户显式的 `language` 值——无法区分「默认留下的中文」与「用户特意选的中文」，静默改写会违背不重写用户数据的原则。

## Considered Options

- **同时把已有的显式 `language: "中文"` 迁移为英文**：会改写用户设置且无法辨别意图，故不做。
- **无条件把示例模板替换为英文**：会覆盖用户对模板的编辑，故改为按 `id` + 旧默认值双重匹配。

## Consequences

- 新安装、以及未显式设置报告语言的用户默认得到英文报告——即使界面是中文（报告语言与界面语言相互独立，见 ADR-0005）。
- 用户从未改动过的中文示例模板会在载入时变为英文；改动过的模板保持原样。
- `test/settings.test.ts` 覆盖空值回退英文与迁移的三种情形（未改动 / 已改动 / 非示例 id）。
