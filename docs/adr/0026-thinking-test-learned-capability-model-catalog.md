# 思考测试回归与两档开关：习得能力盖过能力表，模型清单改挑选制

> **部分取代 [ADR-0024](0024-thinking-off-by-default.md)（「三态」裁撤为两态）与 [ADR-0025](0025-thinking-verification-by-fake-off-warning.md)（「不设测试按钮」「不自动试字段」两裁决取消）**，其余各节继续生效。规格见 issue #86。

规格 #86 落定时三处翻案：① **「思考测试」按钮回归**——当年否决测试按钮的「假 ✅」歧义由新增的**基线对照**消除（先判断模型会不会思考，再依次试固定字段判断能不能关，结论只认响应推理段、不认报错），且它同时解决了自定义供应商暗号参数「用户不识」的问题（按钮自动试字段，无需人工填参）；测试结论落为**「习得能力」**（随设置持久化、带时间戳），解析优先级 **习得能力 ＞ 内置能力表 ＞ 未知**。② **「自动」档裁撤**——自动（不发参数）与开（无开参数时不发）大面积等价（MiniMax-M3 的开参数即 `adaptive`），两档「开 / 关」可换原生开关控件、根治三按钮风格不一致；存量 auto 迁移为 on，出厂默认仍为关。③ **模型列表改挑选制**——「模型清单」（拉取全集）与「启用模型」（用户挑选的子集）分离，拉取不再整体替换启用集，静默拉取只刷清单、永不自动启用。（**2026-11-04 修订（#90，用户裁定）**：静默拉取整体废除，「获取模型列表」按钮＋手动挑选是获取模型的唯一入口；「未配置 ⇒ 无启用模型」回归 #29 不变量，详见 Consequences。）

## Considered Options

- **维持 ADR-0025 置灰、不做测试**：新模型与自定义供应商永远无自助路径，能力表错误只能干等更新——否。
- **手动「思考参数名」＋能力声明（ADR-0024 旧案变体）**：「用户不识暗号」的问题原样存在，被测试按钮完全取代——否。
- **保留三态只换样式**：「自动」语义（听服务端默认）用户无从判断，且与开大面积等价——否。
- **两档语义取「开＝不发参数」（自动并入开）**：默认不思考的模型「开」会成假开；取「开＝发开参数（无则不发）」更兑现用户意图——否。
- **迁移 auto→off（与出厂默认一致）**：会静默扭转已主动选「自动」用户的行为；auto→on 行为几乎不变——取 on。

## Consequences

- **2026-11-04（#90，用户裁定）**：静默拉取废除。背景：两条拉取路径的放行条件分叉——静默拉取只看「密钥名非空」、从不校验密钥值，密钥值缺失时仍发无鉴权请求；手动「获取模型列表」要求密钥名＋密钥值双齐。决定：**获取模型的唯一入口是手动「获取模型列表」按钮＋挑选确认**，打开设置页 / 密钥变更不再自动拉取；「未配置（密钥名为空）⇒ 无启用模型」回归 #29 不变量（清空预设供应商密钥名连带清空启用集与悬空「当前模型」；载入迁移清理存量残留，且排在旧明文密钥迁移之后；自定义供应商模型行与无认证供应商不受影响）。**部分取代本 ADR ③ 的「静默拉取只刷清单」与 #87 的「存量模型全部保留」**；「模型清单」「已失效」语义不变。

- 习得能力成为能力表之外的第二事实源；修正路径为**习得行的「重新测试」文字入口**（清习得并重跑）与**假关告警内的「重新测试」动作**并存。（**2026-11-04 实装修订（#89，用户裁定）**：原稿「假关告警动作是唯一修正路径、设置页不常驻重测入口」与 #86 显示矩阵「转『重新测试』文字入口」及 UI 原型相抵，实装取显示矩阵与原型形态——弱结论（未检出思考 / 未能关闭）亦落习得条目，须留自助修正路径，否则无假关可触发的弱结论将永久锁死。）
- 残余风险接受：静默忽略未知参数的网关若真暗号不在候选清单，测试只能给出「未能关闭」（措辞不写「强制思考」）；基线未检出标「未检出思考」而非「无思考」。措辞全面诚实化。
- 「取消挑选＝移出启用模型」对当前模型采用「受保护、先切换后移除」策略——与 [ADR-0010](0010-active-model-invariant-at-mutation-time.md)「变更命令处清理」并列的姊妹策略（启停是可逆的策展动作，思考偏好与习得数据保留），不改 ADR-0010 的载入不校验决定。
- 测试内 400 是探测信号（换下一个字段），测试外 400 仍归 ai-error 上浮；一次请求只发一个开关参数、默认关、假关判定均不变（ADR-0024 保留）。
- 思考控件摆放（「选择模型」卡内第二行）来自 UI 原型 P1 变体定案，原型归档 throwaway 分支——属可逆的呈现决定，不入 ADR 级约束。
