# 思考测试回归与两档开关：习得能力盖过能力表，模型清单改挑选制

> **部分取代 [ADR-0024](0024-thinking-off-by-default.md)（「三态」裁撤为两态）与 [ADR-0025](0025-thinking-verification-by-fake-off-warning.md)（「不设测试按钮」「不自动试字段」两裁决取消）**，其余各节继续生效。规格见 issue #86。

规格 #86 落定时三处翻案：① **「思考测试」按钮回归**——当年否决测试按钮的「假 ✅」歧义由新增的**基线对照**消除（先判断模型会不会思考，再依次试固定字段判断能不能关，结论只认响应推理段、不认报错），且它同时解决了自定义供应商暗号参数「用户不识」的问题（按钮自动试字段，无需人工填参）；测试结论落为**「习得能力」**（随设置持久化、带时间戳），解析优先级 **习得能力 ＞ 内置能力表 ＞ 未知**。② **「自动」档裁撤**——自动（不发参数）与开（无开参数时不发）大面积等价（MiniMax-M3 的开参数即 `adaptive`），两档「开 / 关」可换原生开关控件、根治三按钮风格不一致；存量 auto 迁移为 on，出厂默认仍为关。③ **模型列表改挑选制**——「模型清单」（拉取全集）与「启用模型」（用户挑选的子集）分离，拉取不再整体替换启用集，静默拉取只刷清单、永不自动启用。

## Considered Options

- **维持 ADR-0025 置灰、不做测试**：新模型与自定义供应商永远无自助路径，能力表错误只能干等更新——否。
- **手动「思考参数名」＋能力声明（ADR-0024 旧案变体）**：「用户不识暗号」的问题原样存在，被测试按钮完全取代——否。
- **保留三态只换样式**：「自动」语义（听服务端默认）用户无从判断，且与开大面积等价——否。
- **两档语义取「开＝不发参数」（自动并入开）**：默认不思考的模型「开」会成假开；取「开＝发开参数（无则不发）」更兑现用户意图——否。
- **迁移 auto→off（与出厂默认一致）**：会静默扭转已主动选「自动」用户的行为；auto→on 行为几乎不变——取 on。

## Consequences

- 习得能力成为能力表之外的第二事实源；假关告警＋告警内「重新测试」动作是它出错时的唯一修正路径（设置页不常驻重测入口）。
- 残余风险接受：静默忽略未知参数的网关若真暗号不在候选清单，测试只能给出「未能关闭」（措辞不写「强制思考」）；基线未检出标「未检出思考」而非「无思考」。措辞全面诚实化。
- 「取消挑选＝移出启用模型」对当前模型采用「受保护、先切换后移除」策略——与 [ADR-0010](0010-active-model-invariant-at-mutation-time.md)「变更命令处清理」并列的姊妹策略（启停是可逆的策展动作，思考偏好与习得数据保留），不改 ADR-0010 的载入不校验决定。
- 测试内 400 是探测信号（换下一个字段），测试外 400 仍归 ai-error 上浮；一次请求只发一个开关参数、默认关、假关判定均不变（ADR-0024 保留）。
- 思考控件摆放（「选择模型」卡内第二行）来自 UI 原型 P1 变体定案，原型归档 throwaway 分支——属可逆的呈现决定，不入 ADR 级约束。
