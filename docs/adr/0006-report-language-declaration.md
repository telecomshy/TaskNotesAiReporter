# 报告语言在两种模式下统一声明输出语言

> **状态**：本文中「空/纯空白回退『中文』」的取值已被 [ADR-0007](./0007-english-defaults-and-example-template.md) 取代，现回退「English」；本文其余决定不变。

「报告语言」此前只在极简模式（未选模板）向提示词追加一行，模板模式下被静默忽略；而任务字段名等提示词脚手架恒为中文。决定：**报告语言只约束报告正文**——无论是否选用模板，都在提示词末尾追加 `输出语言：X。`；任务字段名等机器面向的表示保持固定中文；语言值保持自由文本；空/纯空白回退「中文」。理由：用户真正关心的是模型按所选语言产出，起作用的是明确指令而非字段标签语言；自由文本避免枚举限制。这与 ADR-0005 一致——报告语言独立于界面语言。

## Considered Options

- **模板内提供 `{{language}}` 占位符**：表达力强，由模板作者决定放置；但旧模板没有占位符时仍需兜底追加，等于「末尾追加」外再加一层复杂度。
- **用独立 system message 传语言**：语义最清晰；但需改造 `chatCompletion` 的消息结构以支持多消息，超出本问题范围。
- **把脚手架与任务字段名也按报告语言本地化**：无助于模型遵守输出语言，且会牵动既有中文提示词断言。
- **语言值收窄为枚举（中文 / 英文）**：自由文本更通用，枚举只带来限制。

## Consequences

- 模板模式行为改变：现在会追加语言声明，可能覆盖模板正文里自述的语言——这是有意的（显式设置优先）。
- 极简模式提示词形态变化：语言声明从句首附近移到末尾。
- `test/prompt.test.ts` 覆盖两种模式的末尾声明；`normalizeSettings` 增加空/纯空白回退「中文」。
